# iCodeReviewer 项目会议纪要

**会议时间**：2025年6月14日  
**项目**：AI使能代码检视系统 - Prompt进化算法优化

---

## 核心技术架构

**总体目标**：基于进化算法的prompt自动调优系统

**技术流程**：

```text
Prompt + Code → LLM推理 → LLM生成新Prompt → 进化算法选择最优Top-k → 迭代优化
```

---

## 数据基础与核心关注点

**数据集**：Prime Vul  
**核心目标**：代码问题的精准定位和分类

---

## 评价体系设计

### 主要评价指标

- Pass@k、CodeBLEU

### 多维度中间状态评分机制

- RAG结果与代码问题类型大类的匹配度
- 代码逻辑链分析（引入逻辑距离概念）
- 大模型偏序判断

**解决核心难题**：当两个prompt都表现不佳时，通过中间状态打分区分优劣

---

## 进化算法实施策略

### Prompt变异机制

- **指导策略**：diffusion model限制可行域，指导变异方向
- **变异模板**：基于PPT中的扰动方法
- **多样化目标**：确保prompt变异的多样性

### 选择与优化策略

- **吸收机制**：将能解决新问题的prompt特性融入当前最优解
- **保护机制**：对重要token实施freeze策略

### 知识库构建

- 收集blog中的prompt最佳实践
- 构建RAG系统或直接输出prompt更新策略

---

## 技术借鉴与创新

**借鉴方向**：

- CoT（思维链）：提升推理逻辑
- ICL（上下文学习）：优化prompt效果

**创新点**：将进化算法应用于prompt工程，实现自动化优化

---

**核心思路**：通过进化算法驱动的prompt自动优化，结合多维度评价体系，实现代码漏洞检测的精准性和多样性平衡。
